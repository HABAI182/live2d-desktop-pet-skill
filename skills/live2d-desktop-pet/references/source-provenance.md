## 长离与玄翎两类经验如何合并

| 可迁移的决策 | 不迁移为通用默认 |
| --- | --- |
| 未获认可时改变结构范式 | 所有角色都是粉发、金红眼和凤凰 |
| 获认可后局部修补并对照保护区 | 所有项目都默认使用玄翎底图 |
| 身份、构图、底图的参考职责分离 | 将某张贴纸截图称为官方全视角资料 |
| 键盘用物理空间与配列核对 | 所有构图空格都在画面上方，不看镜头 |
| 有线/无线、配角和特殊纹样按当前契约 | 把案例的五段额纹、某种瞳色写成所有角色硬条件 |
| 清理袖面过度纹饰但保留形制 | 为了减细节随意改手长、袖口和接触点 |

玄翎部分是输入包中的纠错经验，不声称本次重新核实其完整官方设定。目标角色需要准确设定时，以用户资料和当时可读取的官方来源核对，不能凭这个候选图下结论。
