# 参考来源

每个项目分别记录角色身份参考、构图/动态参考和当前编辑底图。用户提供图片不等于取得原角色或第三方作品的公开再分发许可。

只保留推进任务所需的简短来源、可改区域和验收约束；不把完整原始聊天、提示词历史、生成候选和重复报告复制进公开源码。资料缺失时直接说明，不声称恢复了原始像素。

技能已移出两张角色案例位图，来源和 SHA256 见 [素材说明](../assets/ASSET-NOTICE.md)。新项目必须提供自己的底图，不能默认复用旧角色。
