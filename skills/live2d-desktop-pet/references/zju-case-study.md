# 浙大娘桌宠日用打磨案例

此案以长离、秧秧为动作和使用体验的参照，从获认可的浙大娘 Q 版底稿制作原生 Cubism 桌宠。保留原设的蓝白色调、羽饰、轻微头倾和完整校标。参考图用于角色辨识、构图尺幅或动作对照时，分别标注用途。

| 反馈 | 查证与修法 | 验收重点 |
| --- | --- | --- |
| 脸和眼神生硬，稍改便失去原图感 | 锁定认可的脸型和瞳色，用中性、眨眼与四向视线看局部补绘。定位描线归属后再移眉。案例里的眉侧硬线实际在脸底，移动眉层未消除它 | 一对虹膜各自剪贴，闭眼无残虹膜。保留同尺度的改前改后及极值 |
| 鼠标手碰不到鼠标，键盘只有近处 | 按设备透视标出手指接触、物理四区与 Space。鼠标、手掌、随动袖端与设备标识共享位移，按压独立叠加 | 极值下设备与手指接触可信。短按也到达目标，长按保持，松手回位 |
| 摸头后发束露缝，回弹弱或弹多次 | 用深浅底原生渲染锁定断口，补叠层并对齐形变权重。按下一次、松开一次只提交一个头部动作，消除同次原生鼠标边沿的叠加 | 默认和最大幅度组合姿态。片层静态完整、一次回弹、归位、重复短按 |
| 右键打开和拖动时卡顿 | 拆量 WebView 创建、原生位置提交、轮廓读回与绘制。预加载菜单，按帧提交位置，拖动中复用轮廓，松手用可见边界吸附 | 首次和复开窗口、拖动中画面、透明孔洞、贴底、缩放后重启 |
| 浮显挡角色，日用设置难调 | 将气泡和按键移开脸、手与校标，按情境排序。保留字号、放缩、位置、穿透和恢复入口；设置页提供浮显预览 | 最小和最大尺寸、长句六键、设置失焦、重开后的尺寸与位置 |

本案发布到 Windows x64。源码归档重建出相同的 24 个运行资源与 51 层 PSD。Windows 实际检查了 150% 缩放下菜单复用、拖动吸附、透明边缘、设置持久化和便携启动。混合 DPI 跨屏、具体的全屏游戏及真实手柄仍需目标场景测试。
